# History Docs

Cette section contient l'historique de travail et les archives contextuelles.

## Files

- `docs/history/progress.md`
  - journal de progression detaille
  - validations et artefacts
  - idees et notes de suivi

## Usage

- Utiliser cette archive pour comprendre l'historique.
- Ne pas la traiter comme une source d'autorite active.
- Des entrees peuvent mentionner:
  - d'anciens chemins
  - d'anciennes regles
  - des notes verbatim avec encodage heritage

Les regles actives pour l'IA restent dans `AGENTS.md` et `docs/ai/`.
