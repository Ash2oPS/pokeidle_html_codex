# Testing Strategy

## Priority

- save and resume after inactivity
- layout mode switching
- localization fallback
- deterministic combat resolution
- zone progression and unlock logic
- data validation and migrations

## Runtime Cases

- hidden tab resume
- minimized window resume
- mobile sleep and return
- long elapsed-time reconstruction

## Content Cases

- invalid zone links
- missing localized strings
- invalid quest prerequisites
- broken dialogue references

## Principle

- test the contracts that protect architecture first
- tune balance later
