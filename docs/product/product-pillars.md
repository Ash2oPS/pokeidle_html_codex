# Product Pillars

## Project Identity

- Bilingual Pokemon-inspired idle web game set in Sinnoh.
- Intended to be developed with heavy AI assistance while staying constrained by docs, contracts, and clean architecture.
- Static-first delivery and local-only save remain the V1 baseline.

## Gameplay Direction

- Team-building, slot sequencing, typing, reactions, and long-term progression are the core strategic levers.
- Towns, combat routes, quests, gyms, and future events all belong to one shared progression framework.
- The first vertical slice proves the architecture and workflow before content scale.

## Workflow Direction

- The project is strongly data-driven by design.
- Important balancing and content changes should converge toward safer tool-first workflows.
- Documentation is expected to exist before broad AI implementation, not after it.
