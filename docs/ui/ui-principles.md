# UI Principles

- UI must stay compact, colorful, flat, simple, and fast to scan; filler text and redundant chrome are forbidden. [RULE:UI-001]
- Always-on gameplay uses compact HUD surfaces, while deep interactions use larger focus windows in the project PC-window language. [RULE:UI-002]
- Desktop landscape and mobile portrait are distinct intentional layouts rather than shrink-only variants. [RULE:UI-003]
- Every visible label must justify its footprint; prefer grouping, hierarchy, icons, and state cues before explanatory text. [RULE:UI-004]
- Visual styling uses restrained flat surfaces, disciplined spacing, readable color coding, and minimal decorative clutter while staying consistent with the Pokemon-adjacent direction. [RULE:UI-005]
