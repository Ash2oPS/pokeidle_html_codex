# UI Principles

## Core Direction

- compact
- colorful
- flat
- simple
- fast to scan
- no wasted text

## Structure

- compact HUD for always-on gameplay information
- large focus windows for deep interactions such as the Pokedex
- focus windows use the project PC-window visual language

## Responsive Rule

- desktop landscape and mobile portrait are separate intentional layouts
- mobile is not a shrunk desktop HUD
- reorganize information for the available space

## Text Rule

- every visible label must justify its footprint
- prefer icons, grouping, and color before explanatory filler copy
- put detailed explanations in focus views or optional details

## Visual Rule

- use a restrained flat style
- avoid thick chrome, bloated padding, and decorative clutter
- use color for category, state, and urgency
