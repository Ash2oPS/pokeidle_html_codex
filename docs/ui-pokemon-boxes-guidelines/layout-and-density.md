# Layout And Density

## Core rules

- The interface must occupy the full screen on both desktop and phone.
- Prefer internal scrolling zones over a floating centered mockup.
- Show as many useful items as possible above the fold.
- Push compactness aggressively while readability still holds.

## Sizing rules

- Keep headers short.
- Keep spacing tight and deliberate.
- Make cards, pills, tabs, and panels follow one unified sizing system.
- Make component footprints small by default, then only grow elements that truly need emphasis.

## Content reduction

- Remove helper text, badges, or counters when they do not help the immediate task.
- Prefer direct values over descriptive sentences.
- Do not let the info panel steal height from the box grid unless the user is clearly in an inspection flow.
