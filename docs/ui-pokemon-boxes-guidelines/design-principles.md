# Design Principles

## Visual direction

- Use a modern flat design, not a muddy or generic mockup style.
- Make the interface clearly Pokemon-themed through structure, palette, and states.
- Keep one coherent visual language across shell, cards, pills, tabs, and info panels.
- Avoid leftover styling from older iterations. Every component must belong to the same family.

## Information hierarchy

- Put the grid and actionable content first.
- Keep the selected-Pokemon panel secondary to the main grid.
- Remove explanatory copy when the context is already obvious.
- Keep labels short and direct.

## Component behavior

- Center content inside buttons, tabs, chips, and slot cards.
- Reserve strong accents for real states such as active selection.
- Keep visual chrome restrained. Decorative effects must support hierarchy, not fight it.
