# Public downloads

This folder is committed on purpose so the public GitHub repository can expose the latest APK and
Electron installer without GitHub Releases.

Stable file names:
- `PokeIdle-Android.apk`
- `PokeIdle-Windows-Installer.exe`

Metadata:
- `manifest.json`

To refresh the tracked binaries after building locally:

```bash
npm run downloads:refresh
```
